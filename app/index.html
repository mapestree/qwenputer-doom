Qwenputer viewer — a RISC-V computer inside Qwen3.5-4B's weights

How to read this

Qwen writes a calc tool call. Then 11 compiled layers in front of Qwen's own run a real RV32IM CPU: each executed instruction is one record of "chip tokens" (the colored pills). The CPU's registers, RAM and program counter live in Gated-DeltaNet state. The firmware is calc.c (a bignum calculator using an 8×128-digit "digit file" coprocessor). Qwen never sees those tokens; it only reads the printed answer.

This page decodes the stream with a shadow reference machine (it must match token for token) and shows the machine state. Use the slider / play to replay the run.
